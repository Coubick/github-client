# Git Source

Мобильный клиент для GitHub, написанный на Kotlin для платформы Android с использованием Jetpack Compose. Приложение позволяет просматривать популярные репозитории, искать проекты и изучать их детали после авторизации через GitHub OAuth.

## Возможности

- **Вход через GitHub OAuth** — авторизация без ввода пароля в приложении, токен сохраняется локально (DataStore) и подставляется в запросы автоматически
- **Популярные репозитории** — лента проектов, отсортированная по числу звёзд
- **Поиск репозиториев** — поиск по API GitHub
- **Детали репозитория** — описание, звёзды, форки, язык, данные автора и другие метаданные
- **Выход из аккаунта** — очистка сохранённого токена

## Технологии

| Технология           | Библиотеки |
|----------------------|---|
| Язык                 | Kotlin 2.2 |
| UI                   | Jetpack Compose, Material 3 |
| DI                   | Hilt (Dagger) + KSP |
| Сеть                 | Retrofit, OkHttp, Gson |
| Загрузка изображений | Coil 3 |
| Хранение данных      | Jetpack DataStore (Preferences) |
| Навигация            | Jetpack Navigation (Fragment-based host + Compose-экраны) |
| Архитектура          | Многоуровневая: `data` / `domain` / `presentation` (MVVM, однонаправленный поток данных: Action → ViewModel → State → Screen → Event) |

## Структура проекта

```
app/src/main/java/ru/example/gitsource/
├── data/               # Слой данных: реализация репозиториев, DTO, сеть, локальное хранилище
│   ├── auth/           #   OAuth-логин, TokenManager, AuthTokenInterceptor
│   ├── network/        #   Retrofit-клиент, API-интерфейсы, обработка ошибок
│   ├── local/          #   DataStore
│   └── dto/            #   Модели ответов GitHub API
├── domain/             # Слой домена: сущности и интерфейсы репозиториев
├── di/                 # Hilt-модули
├── presentation/       # UI-слой по экранам
│   ├── auth/           #   Экран входа
│   ├── popular/        #   Лента популярных репозиториев
│   ├── search/         #   Поиск
│   ├── details/        #   Детали репозитория
│   ├── navigation/     #   Navigator и маршруты
│   └── ui/             #   Переиспользуемые Compose-компоненты
└── theme/              # Цвета и темы Compose
```

## Требования

- JDK 17
- Android SDK (compileSdk 37, minSdk 26)
- Android Studio (или просто Gradle + командная строка)
- Зарегистрированный GitHub OAuth App

## Использование

1. При первом запуске нажмите **Sign in with GitHub** — откроется браузер с экраном подтверждения OAuth.
2. После подтверждения вы вернётесь в приложение по deeplink `gitsource://oauth`, токен будет сохранён.
3. Просматривайте популярные репозитории, ищите проекты и открывайте карточки деталей.
